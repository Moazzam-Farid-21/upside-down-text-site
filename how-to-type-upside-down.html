How to Type Upside Down: 4 Ways That Actually Work

Guide · 6 min read · Updated November 18, 2026

There is no upside down mode on a normal keyboard, so you cannot simply hold a key and type flipped letters. What you can do depends on where the text is going. If it is headed for a chat, a bio or a post, you need real text that already looks flipped. If it is headed for a slide or a printed card, you can just rotate it. Here are the four methods people actually use, and when each one is the right choice.

Method 1: Copy and paste flipped Unicode text

This is the method for Facebook, Instagram, TikTok, WhatsApp, Discord, iMessage and anywhere else you type text into a box. A generator swaps every letter for a Unicode character that looks like it has been turned upside down, then reverses the order so the line reads correctly when you rotate your screen.

  1. Open the upside down text generator and type your sentence.
  2. Leave the Upside Down tab selected and press Copy.
  3. Paste it into your message, bio or post.

For example, “hello” becomes oןןǝɥ, “Good morning” becomes ƃuᴉuɹoɯ poo⅁, and “I love you” becomes noʎ ǝʌoן I. Notice that the words appear in the opposite order to how you typed them. That is intentional, because a half turn reverses the line as well as the letters. If you only need one character, the upside down alphabet chart lets you copy letters, numbers and symbols one at a time.

The catch is that this is a clever use of Unicode, not a setting. Some capital letters and symbols have no convincing twin and stay as they are, and a few older apps show an empty box for characters they cannot draw. If you see boxes, read why upside down text shows boxes instead of letters.

Method 2: Rotate a text box in Word, Slides or Canva

In Microsoft Word, PowerPoint, Google Slides and most design tools you can put your text in a text box and rotate the box 180 degrees. Many apps do this with a rotate handle, or with a “Rotate right 90°” command used twice. Exact menu names change between versions, so look for the rotate option on the text box.

This is the right choice for printed invitations, slides and posters, because the result looks perfect and uses any font you like. The limitation is that the text underneath is still ordinary text. If you copy it into a chat, it arrives the normal way up. For anything that has to travel as text, use Method 1.

Method 3: Use CSS on a web page

If you build websites, you can flip text visually with a single line of CSS. The element needs to be a block or inline-block, because transforms do not apply to plain inline text:

.upside-down {
  display: inline-block;
  transform: rotate(180deg);
}

An advantage of this approach over Unicode is accessibility. The words in the page are still normal words, so screen readers and search engines read them correctly. Only the picture on screen is rotated. The downside is that visitors cannot copy it as flipped text.

Method 4: Type upside down punctuation from the keyboard

Two upside down characters are built into most keyboard layouts because Spanish uses them: the inverted question mark and the inverted exclamation mark.

  • Windows: hold Alt and type 168 on the number pad for ¿, or 173 for ¡.
  • Mac: press Option + Shift + ? for ¿, and Option + 1 for ¡.
  • Phones: on many keyboards, press and hold the ? or ! key and choose the inverted version from the pop-up.

These work only for those two marks. Letters need Method 1.

If you mean writing upside down by hand

Writing upside down on paper is a separate skill. A practical way to learn is to write your sentence normally, then turn the page around and trace each letter in its rotated form until the shapes feel familiar. Start with symmetrical letters such as o, s, x and z, which look the same either way up, then move on to the harder ones like a, e and g.
